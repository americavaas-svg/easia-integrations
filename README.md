# EasIA Integrations - Voice Booking Agent

**Twilio Voice + OpenAI Realtime + WhatsApp + Google Calendar + Google Sheets**

Cliente llama → Agente IA atiende → Confirmación automática por WhatsApp + Calendar + Excel

## Stack

- **Twilio Voice:** Recibe llamadas telefónicas
- **OpenAI Realtime:** Agente IA conversacional en tiempo real
- **Twilio WhatsApp:** Envía confirmación por mensaje
- **Google Calendar:** Registra cita automáticamente
- **Google Sheets:** Excel con datos de citas
- **Make.com:** Orquestación sin código
